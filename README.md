# FluxSHARE

Cross-platform peer-to-peer LAN file sharing desktop application.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v20 or higher recommended)
- [npm](https://www.npmjs.com/) (v10 or higher)

### Installation

1. Clone the repository and install dependencies:
```bash
npm install
```

### Development

To start the development servers:
```bash
npm run dev
```

- **Desktop Application**: `npm run dev:desktop`
- **Signaling Server**: `npm run dev:signaling`

### Building for Production

To build all packages and applications:
```bash
npm run build
```

### Testing & Linting

```bash
npm run test
npm run lint
```
